# Catalog Analysis

A small Python console program that analyzes a hard-coded movie catalog and prints a report in Russian. It demonstrates basic Python topics including numeric calculations, conditionals, loops, string processing, lists, dictionaries, sets, generators, and report formatting.

## Requirements

- Python 3.12 or newer
- [uv](https://docs.astral.sh/uv/)

## Run

From the project directory:

```sh
uv run catalog_analysis.py
```

`uv` uses the project's configuration and creates or updates the environment as needed.

## Style check

Run Ruff from the project directory:

```sh
uv run ruff check
```

Ruff settings are defined in `pyproject.toml`.
